감사합니다 앱은 회원가입 없는 익명 서비스로, 별도의 계정이 존재하지 않습니다. 사용자가 직접 작성한 감사 기록은 앱 안에서 직접 삭제할 수 있고, 그 외 데이터는 이메일로 삭제를 요청할 수 있습니다.

1. 앱 내에서 직접 삭제하는 방법

  1. 앱의 "오늘의 감사" 또는 "감사 게시판" 화면에서 본인이 작성한 글을 찾습니다.
  2. 글 카드 우측 상단의 더보기(⋮) 아이콘을 누릅니다.
  3. "삭제"를 선택하고 확인합니다.

삭제된 기록은 즉시 영구적으로 제거되며 복구할 수 없습니다.

2. 이메일로 삭제를 요청하는 방법

아래 항목은 앱 내에서 직접 삭제할 수 없으므로, 이메일로 요청하면 본인 확인 후 삭제해 드립니다.

  • 개발자 후원(인앱결제) 시 남긴 응원 메시지 및 발신 정보
  • 익명 식별자(uid)와 연결된 모든 기록 전체 삭제(앱을 더 이상 사용하지 않는 경우)

요청 방법: yhb4ever@gmail.com으로 삭제를 원하는 내용과, 확인 가능한 익명 식별자(uid, 설정 화면에서 확인 가능) 또는 후원 시 사용한 이메일을 함께 보내주세요.

3. 삭제/보관되는 데이터 유형 및 보관 기간

  • 감사 기록(글 내용, 작성 시각, 공개 여부): 사용자가 앱 내에서 삭제 시 즉시 삭제. 이메일 요청 시 확인 후 7일 이내 삭제.
  • 익명 식별자(uid): 개인을 식별할 수 없는 임의의 값으로, 이메일 요청 시 연결된 모든 기록과 함께 삭제.
  • 후원(인앱결제) 응원 메시지: 이메일 요청 시 확인 후 7일 이내 삭제.
